## 발견 사항과 후속 확인

- 로컬 `.env`가 없는 CI에서 브라우저 테스트가 로딩 중 실패하는 문제 수정. 환경 변수 입력 및 누락 값 안내 추가.
- 기존 브라우저 업무 흐름이 검토자 권한으로 작업 시작·제출까지 수행하던 검증 공백 보완. 실제 실행자 로그인으로 처리 후 검토자로 전환한다.
- GitHub의 느린 응답 환경에서 성공 안내와 목록 로딩 안내가 동시에 나타나 모호한 `status` 선택자로 브라우저 테스트가 실패했다. 기대 문구로 상태 요소를 한정하도록 수정했다. 계정 생성 자체는 성공했으며 제품 기능 실패는 발견되지 않았다.
- 실제 업무 적합성은 [자료 준비 양식](materials-checklist.md)에 따라 회사가 허용한 환경·자료와 담당자가 별도로 검증해야 한다. 확인 주체는 미정.
- 배포, 백업·복구, OCR, 악성 파일 검사는 이번 범위에 포함하지 않았다.
