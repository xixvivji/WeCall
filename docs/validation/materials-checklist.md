# 실무 검증 자료 준비 양식

실제 회사 자료 확보·사용 허가는 아직 확인되지 않았다. 공개 배포나 외부 업로드 지시가 아니며, 이 문서를 채우기 위해 원본 기밀 문서를 Git에 넣지 않는다. 허용 범위가 정해지기 전에는 합성 자료로 진행한다.

## 이미 준비된 자료

[samples/recall-001](../../samples/recall-001/README.md)에 회수 원문, CSV 5종, 조건 입력, 입고 증거 제안과 승인 전후 정답표가 있다. 이 자료는 합성이며 고객사의 실제 문서 형식·업무 빈도·효과를 입증하지 않는다.

## 요청할 최소 자료

| 자료 | 확인할 내용 | 민감 정보 처리 |
| --- | --- | --- |
| 회수 요청 예시 | 제조사·상품 규격·제조번호·소비기한 조건과 원문 인용 | 담당자 연락처·서명·계좌 등 불필요 정보 제외 |
| 입고명세서 예시 | 특정 입고일·상품·전체 수량·제조분이 실제로 확인되는지 | 거래처명·주소·단가 사용 필요 여부를 먼저 결정 |
| 상품·입출고 CSV 예시 | 필드 매핑, 단위, 식별자, 연결 근거 및 누락 형태 | ID를 바꿀 때 파일 간 참조를 함께 바꿔 의미 보존 |
| 담당자 정답표 | 대상/비대상/확인 필요 및 이유, 근거 위치 | 확인 불가능은 추정하지 말고 미확인으로 기록 |
| 업무 흐름 설명 | 누가 조건·증거·증빙을 검토하고 종료하는지 | 개인 이름 대신 역할로 기재 가능 |

익명화는 외부 전송 허가를 뜻하지 않는다. 실제 자료를 받을 위치·접근 권한·보관 기간은 회사가 승인한 범위로 별도 정한다. 승인 증빙 위치도 저장소에는 식별자만 남길 수 있다.

## 자료 접수 카드 — 미작성

| 항목 | 작성 값 |
| --- | --- |
| 자료 묶음 ID / 제공일 / 제공 책임 역할 | 미정 |
| 자료 목적 / 허용 사용자 / 허용 환경 | 미정 |
| 합성·공개·익명화 실무·실제 원본 구분 | 미정 |
| 회사 사용 승인 근거 위치 | 미정 |
| 외부 AI·OCR·Git·클라우드 전달 가능 여부 | 미정 |
| 익명화 범위와 파일 간 ID 매핑 검증자 | 미정 |
| 보관 기간 / 삭제 책임 역할 / 승인 방식 | 미정 |
| 정답 검토 역할 / 검토일 / 불확실 항목 | 미정 |

## 정답 행 양식

`자료 묶음 ID, 데이터 버전, 기록 유형, 기록 ID, 기대 판정, 기대 수량, 원문 근거 위치, 판단 이유, 불확실성, 검토 역할, 검토일`

표본에는 대상·비대상·제조번호 누락·소비기한 누락·부분 연결·수량 충돌을 포함한다. 정답은 시스템 출력을 복사해 만들지 않고 업무 근거로 먼저 작성한다. 판정 조건상 누락이 결과에 영향을 주지 않는 사례도 넣는다. 첨부 기능 검증용 PDF·PNG·JPEG는 우선 합성 자료로 만들며 실제 서명·계좌·연락처는 사용하지 않는다.
