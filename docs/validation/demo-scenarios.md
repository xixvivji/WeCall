# 검증·시연 시나리오

기준일 2026-09-13. 실제 출고 중지나 회수 실행이 아닌 합성 자료 시연이다. [샘플](../../samples/recall-001/README.md)과 정답표를 기준으로 한다. 아래 표의 관찰 결과 칸은 새 검증 때 작성한다.

## 환경과 실행

[README 실행 방법](../../README.md)으로 PostgreSQL·Spring·Vue를 준비한다. 로그인 계정은 로컬 `.env`에서 읽으며 기록표·스크린샷·Git에 비밀번호를 복사하지 않는다. 두 역할을 각각 확인한다. 실제 AI 서버는 기본 업무 시연에 필요하지 않다.

```sh
# 저장소 루트에서
python3 scripts/validate_sample.py
./backend/gradlew -p backend test
# 프론트 디렉터리에서
npm run build
npm run test:e2e
```

백엔드 통합 테스트는 Docker의 테스트용 PostgreSQL이 필요하고, 브라우저 테스트는 실행 중인 로컬 서버와 합성 시연 계정이 필요하다. 브라우저 테스트는 합성 사건·데이터·계정을 생성하므로 데이터가 누적된다. 임의의 실제 업무 DB에 테스트 데이터를 넣지 않는다.
