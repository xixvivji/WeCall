# 원문 변경 후 재검토 검증 — 2026-09-18

- 백엔드 129개 테스트 및 bootJar 빌드 통과.
- 프론트 타입 검사·빌드, 전체 테스트 28개(계산 2개·브라우저 26개) 통과.
- [GitHub CI](https://github.com/xixvivji/WeCall/actions/runs/35293756090): 구현 커밋 `8e62972`의 백엔드·AI 계약·프론트 빌드·브라우저 및 HTTP 업무 인수 검사 통과.
- 실제 API·브라우저 합성 흐름: 조건 승인·판정 → 원문 v2 수정 → 판정 버튼 차단·검토 대기함 표시 → 영향 없음 사유·확인 → 새 판정 허용 → 원문 v3 수정 → 다시 검토 필요 → 불필요한 초안 철회 → 실행 담당자 읽기 전용 확인.
- API 검증: 재검토 전 종료·판정 차단, 재검토 후 기존 판정 수량 보존과 종료 스냅샷의 현재/판정 당시 버전 분리, 원문을 원래 내용으로 복원해도 재검토 필요, 근거 인용 삭제 시 영향 없음 거부, 구버전·중복·다른 사건·권한·종료 상태 차단.
- 오래된 초안 승인·판정 거부 및 철회 후 새 조건·판정 경로를 확인했다. 승인된 조건은 철회할 수 없다.
- 이전 원문 조건을 입고 증거 승인으로 복제해 현재 조건으로 우회하는 시도를 거부하고 데이터·조건이 추가되지 않음을 확인했다.
- 과거 기준 원문 NULL은 그대로 유지하며 검토 기록을 추가해 해소하는 경로를 검증했다. 대기함 테스트의 기존 SQL 합성 조건도 NULL인 경우 SOURCE 대기를 포함하도록 기대값을 보완했다.
- 로컬 V12 DB에 V13 마이그레이션 성공. 파일·AI 모델·원문 텍스트·기존 판정 결과를 수정하지 않았다.

실제 회사 자료와 새 AI 프레임워크는 사용하지 않았다. 이번 변경은 Spring의 업무 검토 상태와 화면을 보완하며, 모델 정확도 개선이나 실무 인수 완료를 뜻하지 않는다. 과거 원문 버전 미기록 조건은 사용자 재검토가 필요할 수 있다.
