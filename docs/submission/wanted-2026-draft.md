# 원티드 AI Championship 2026 제출 초안

2026-09-20 실제 접수 화면에서 항목 확인. 아직 제출하지 않았다. GCP 공개 HTTPS와 실제 AI 업무 흐름을 검증했고 이미지 5장을 준비했다.

## 제목

WeCall — AI로 근거를 연결하는 식품 회수 대응

## 해결하고자 한 문제

식품 회수 공문과 상품·입고·재고·출고 기록이 흩어져 있으면 회수 대상과 대응 범위를 확인하기 어렵습니다. WeCall은 원문 근거를 검토 가능한 조건으로 바꾸고, 정보가 부족한 건은 ‘확인 필요’로 남겨 담당자의 판단과 후속 대응을 연결합니다.

## AI 활용 방식 및 결과 (500자 이내)

WeCall은 식품 회수 공문의 비정형 문장을 AI로 분석해 제조번호·소비기한 등 회수 조건과 원문 근거를 검토 가능한 초안으로 변환합니다. FastAPI·Ollama 기반의 Qwen3 4B 자체 호스팅 모델을 사용하며 외부 모델 API로 문서를 전송하지 않습니다. 담당자가 상품 연결과 조건을 검토·승인하면 규칙 엔진이 재고·출고 영향을 판정하고, 정보가 부족한 항목은 ‘확인 필요’로 남깁니다. 이후 입고 증거 보완에 따른 재판정과 대응 작업·증빙 이력까지 연결합니다. 합성 검증 35건에서 추출 19건·거절 16건이 기대 결과와 일치했고, GCP CPU 서버에서 실제 AI 분석을 포함한 전체 업무 흐름을 102초에 검증했습니다. 이는 사전 검사를 포함한 제한된 테스트 결과입니다. 공개 샘플은 저장된 예시이며 실제 분석은 로그인 후 이용합니다.

## 사용 AI툴 및 기술 스택

- 제작 AI 도구: OpenAI Codex. 체크박스에 Codex가 없고 서비스 설명에서는 분리했다. 대회가 제작 도구 명칭·활용 방식 기재를 요구하므로 최종 제출 전에 별도 표기 위치를 정한다. ChatGPT 등 실제로 별도 사용한 도구는 본인 확인 후 선택한다.
- 구현: Java 21, Spring Boot 3.5.16, Gradle 8.7, PostgreSQL, Vue 3, TypeScript, Vite, FastAPI, Ollama, Qwen3 4B.
- 배포 완료: Google Cloud CPU VM. Vercel 연결은 GitHub 본인 인증 대기 중이다.

## 제출 전 남은 사항

- GCP 무료 체험 크레딧 414,984원·만료일 2026-12-20 확인. 유료 전환 없이 e2-standard-4 CPU 배포로 결정.
- 14일 = 336시간. 실제 리전의 VM·GPU·디스크·공인 IP·전송료를 합산해 예산 확정.
- Vercel은 Vue 정적 프론트, GCP는 Spring Boot·PostgreSQL·FastAPI·Ollama 실행 후보. API는 HTTPS 리버스 프록시로 연결하고 세션·CSRF·업로드를 검증한다.
- GPU 없이 실제 모델 분석·검토·재판정·작업 완료 검증에 성공했다. CPU 모델 처리 제한은 300초다.
- 예산 알림은 자동 지출 차단이 아니다. 유료 계정 전환이나 크레딧 초과 지출은 별도 결정이 필요하다.
- 익명 실제 AI 체험의 방문자별 격리·요청 제한은 아직 구현 완료로 주장하지 않는다.
- 심사 기간 동안 접속 유지. 이 화면의 마감일은 2026-09-20이며 임시저장만으로는 제출되지 않는다.
