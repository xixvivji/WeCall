# 원티드 AI Championship 2026 제출 초안

2026-09-20 실제 접수 화면에서 항목 확인. 아직 제출하지 않았으며 서비스 URL·이미지는 배포 확인 후 채운다.

## 제목

WeCall — AI로 근거를 연결하는 식품 회수 대응

## 해결하고자 한 문제

식품 회수 공문과 상품·입고·재고·출고 기록이 흩어져 있으면 회수 대상과 대응 범위를 확인하기 어렵습니다. WeCall은 원문 근거를 검토 가능한 조건으로 바꾸고, 정보가 부족한 건은 ‘확인 필요’로 남겨 담당자의 판단과 후속 대응을 연결합니다.

## AI 활용 방식 및 결과 (500자 이내)

제작에는 OpenAI Codex를 활용해 설계 보완, Java·Spring Boot 백엔드와 Vue 화면 구현, 테스트 작성·실행을 진행했습니다. 서비스에서는 FastAPI·Ollama의 Qwen3 4B 로컬 모델이 회수 공문의 제조번호·소비기한 조건과 원문 근거를 구조화합니다. 사람의 상품 연결 검토·승인 뒤 규칙 엔진이 재고·출고 영향을 판정하며, 누락 정보는 ‘확인 필요’로 유지합니다. 입고 증거 보완에 따른 재판정과 대응 작업·증빙 이력을 연결했습니다. 작은 합성 회귀 세트 35건에서 추출 19건·거절 16건이 기대 결과와 일치했습니다. 사전 검사도 포함된 결과이며 현업 정확도를 뜻하지 않습니다. 공개 샘플은 저장된 예시이고 실제 모델 분석은 별도 업무 기능입니다.

## 사용 AI툴 및 기술 스택

- 제작 AI 도구: OpenAI Codex. 체크박스에 Codex가 없으므로 설명 본문에 명시. ChatGPT 등 실제로 별도 사용한 도구는 본인 확인 후 선택한다.
- 구현: Java 21, Spring Boot 3.5.16, Gradle 8.7, PostgreSQL, Vue 3, TypeScript, Vite, FastAPI, Ollama, Qwen3 4B.
- 배포 예정: Google Cloud, Vercel. 배포가 완료되기 전에는 완료로 기재하지 않는다.

## 서비스 링크

미정 — 공개 HTTPS 주소에서 비로그인 샘플과 심사용 실제 업무 접근을 검증한 뒤 입력한다. localhost 링크를 제출하지 않는다.

## 대표 이미지·스크린샷

실제 화면 캡처를 사용한다. 스크린샷은 최대 5개, 16:9 비율이다.

1. 대표: WeCall 첫 화면.
2. 합성 샘플의 원문과 AI 초안 예시. 예시 표시를 유지한다.
3. 대상·비대상·확인 필요 수량과 판단 근거.
4. 입고 증거 보완 전후 판정 비교.
5. 대응 작업·증빙 검토.

실제 모델 화면을 사용할 경우 실제 실행 결과를 확인한 뒤 캡처한다. 계정 정보·개인정보·회사 문서를 넣지 않는다.

- GCP 무료 체험 크레딧 414,984원·만료일 2026-12-20 확인. 유료 전환 없이 e2-standard-4 CPU 배포로 결정.

- GPU는 사용하지 않는다. 현재 모델을 CPU에서 실측하고 시간 제한과 결과를 검증한다.
- 예산 알림은 자동 지출 차단이 아니다. 유료 계정 전환이나 크레딧 초과 지출은 별도 결정이 필요하다.
