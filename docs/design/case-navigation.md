# 사건 화면 이동과 공유 링크

사건 탭과 기준 판정을 URL의 `tab`, `assessment` 값으로 유지한다. 새로고침·브라우저 뒤로/앞으로 이동 시 같은 화면을 열 수 있다. ‘현재 화면 링크 복사’는 해당 화면과 판정 식별자를 포함한 링크를 복사한다. 링크 접근에는 기존 로그인이 필요하다.

- 지원 탭: overview, impact, comparison, evidence, tasks, closure, history, report.
- assessment가 생략된 기존 링크는 최초 조회 시 최신 판정을 선택한다. 화면 이동/링크 복사 시 선택된 판정 ID를 포함한다.
- `assessment=`는 사용자가 판정을 선택하지 않은 상태다. 이후 판정이 추가돼도 새로고침으로 자동 선택하지 않는다.
- 해당 사건에 없는 판정 ID는 오류로 알린다. 다른 판정으로 자동 대체하지 않고 드롭다운에서 다시 선택할 수 있다.
- 기존 task/proof, evidence, condition 링크를 유지한다. 명시된 상세 대상은 기본 탭보다 우선한다. 일반 탭 버튼을 누르면 상세 대상 query를 제거한다.
- 탭/기준 판정 변경은 화면 이동이다. 작성 중인 폼의 자동 저장 기능은 포함하지 않는다. 서버에 저장된 업무 기록과 판정은 변경하지 않는다.
- 판정 실행·입고 증거의 결과 판정 열기는 해당 판정의 영향 조회 화면으로 이동한다.
- 링크의 판정은 저장된 판정 결과이고, 업무 이력·작업·보고서의 현황은 조회 시점에 따라 달라질 수 있다.

검증: navigation.spec.ts의 탭 새로고침·브라우저 이력·링크 복사·없는 판정 오류·미선택 복구·모바일 너비, report.spec.ts의 명시적 판정 선택·새로고침과 보고서 검증. 기존 업무 시나리오 전체도 함께 실행한다.
