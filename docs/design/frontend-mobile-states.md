# 모바일 화면과 조회 상태 마무리

2026-09-15 기준. AI와 배포는 포함하지 않는다.

## 화면 변경

- 긴 사건명·계정명·식별자·오류 문구가 카드와 페이지 너비를 늘리지 않도록 줄바꿈한다.
- 모바일 표의 셀 여백을 줄이고 표 내부 가로 스크롤을 유지한다. 계정 표에는 스크롤 안내와 키보드 포커스를 제공한다.
- 모바일 페이지 이동·폼 버튼은 줄바꿈하고 로딩·빈 화면의 여백을 줄인다.
- 사건 최초 조회에는 로딩 안내를 표시한다.
- 계정 목록과 변경 이력은 로딩·조회 실패·실제 빈 결과를 구분한다. 실패한 목록에 잘못된 0명이나 빈 이력 안내를 표시하지 않는다.
- 변경 이력 재시도는 작성 중인 상태 변경 사유를 보존한다.
- 조건 작성의 데이터 버전 선택은 로딩·실패·빈 결과와 등록 링크를 제공한다. 조회 실패 시 이전 페이지의 선택지를 숨기고 재시도를 제공한다.

## 검증

프론트 빌드 성공. 기존 전체 24건 통과 후 데이터 선택 검증을 추가했고, 영향받는 모바일 상태·사건 이동 3건을 다시 통과했다. `frontend/e2e/mobile-states.spec.ts`는 390px 화면의 페이지 넘침 방지, 표 내부 스크롤, 목록/이력 오류 복구, 메모 보존, 지연된 데이터 조회와 실패 후 빈 결과를 검증한다. 스크린샷은 합성 데이터로 확인했다. 최종 전체 검증 결과는 CI에서 확인한다.

실제 회사 자료를 이용한 사용자 검수, 실제 악성 파일 검사 엔진 연결, AI와 OCR 구현, 배포 운영 검증은 별도 남은 작업이다.
