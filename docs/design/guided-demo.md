# 로그인 없는 합성 샘플 체험

2026-09-18 구현. 경로는 `/#/demo`이며 로그인 화면의 ‘샘플 체험 시작’ 또는 업무 메뉴의 ‘샘플 체험’에서 진입한다. 이번 작업에는 외부 배포나 대회 제출 자료 제작을 포함하지 않는다.

## 체험 범위

1. 가상 공급사 공문의 상품·제조번호·소비기한 확인.
2. 준비된 AI 조건 초안 예시와 근거 확인. 실제 모델을 호출한 것처럼 로딩·완료를 연출하지 않는다.
3. 규격·제조사별 상품 연결 예시를 읽고 확인 체크 후 샘플 조건 승인.
4. 합성 정답표의 재고·출고 대상/비대상/확인 필요 수량 확인.
5. R4 입고 근거 확인 후 보완 전·후 판정 예시 비교. S2의 연결 미확인 10 EA는 그대로 남긴다.
6. I1 격리 작업 1건의 시작·증빙·검토·완료 순서와 사건 종료 불가 사유 확인.

체험 완료는 사건 종료가 아니다. 작업 완료 건수를 회수 실적 수량으로 바꾸지 않고, 남은 대상 전체의 대응이 완료됐다고 표시하지 않는다. 이전 단계는 다시 볼 수 있고, 승인/근거 확인 전 이후 단계로 넘어가지 않는다. 초기화는 확인 후 현재 탭의 체험 상태만 지운다.

## 데이터 보호 방식

이 화면은 백엔드 연결과 무관하게 동작하는 제한된 설명용 체험이다. 업무 API·모델 호출·업로드·자유 입력을 제공하지 않는다. 로그인·공유 계정·데이터베이스 복제가 필요하지 않다. Vue 컴포넌트별 메모리에만 진행 상태를 두며 localStorage/sessionStorage/cookie에 저장하지 않는다. 다른 탭·방문자와 진행 상태가 공유되지 않고 새로고침 시 초기화된다.

실제 업무 API의 인증·권한은 그대로 유지한다. 데모 진입으로 권한이나 서버 세션을 발급하지 않는다. 로그인한 사용자가 체험하더라도 체험 버튼은 실제 사건을 변경하지 않는다. 업무 화면으로 돌아오면 서버 세션을 다시 확인한다. 직접 데모 주소로 진입할 때에는 세션 API도 요청하지 않는다.

이 보호는 **샘플 체험에 한정**된다. 실제 업무는 기존 단일 기업·역할 권한 모델이며, 실제 검토자 계정을 불특정 다수에게 공유해도 안전하다는 의미가 아니다. 향후 실제 AI를 일반 방문자에게 제공하려면 별도 접근 정책·자원 제한·체험별 저장 공간을 검토해야 한다. 배포 시 합성 예시 화면과 실제 AI 운영 범위를 정확히 표시한다.

## 합성 자료와 검증

`frontend/src/demo/sample.json`은 `samples/recall-001`의 가상 공문·증거·상품·조건·정답표에서 만든 번들이다. `demo.spec.ts`가 원본과 일치하는지 확인한다. 회사 자료나 실제 식품 회수 공문을 넣지 않는다.

신규 검증은 다음을 포함한다.

- API 연결을 차단한 상태에서 전체 체험 진행과 승인·검토 단계 차단.
- 체험 중 API 요청 0건, 저장소 기록 없음, 두 탭의 독립 상태.
- 초기화 취소·확인, 새로고침 초기화, 실제 사건 종료와 체험 완료 구분.
- 모바일 가로 넘침 없음, 상품 표 내부 스크롤.
- 비로그인 사용자의 사건·데이터·계정 읽기와 CSRF를 포함한 사건 생성 요청 차단.
- 로그인한 사용자의 체험 전·후 업무 사건 응답 동일, 복귀 시 세션 재확인.

실제 로컬 AI 검증은 [MVP 마무리 기록](../validation/mvp-completion-2026-09-18.md)을 따른다. 샘플 체험 테스트는 실제 모델 평가의 대체물이 아니다.
