# 프론트 시각 스타일 — 2026-09-18

사용자가 제시한 [SK AX 홈페이지](https://www.skax.co.kr/)의 짙은 배경, 푸른 빛의 흐름, 큰 제목과 여백을 참고해 WeCall의 업무 UI에 적용했다.

- 로그인과 사건 목록 첫 영역에 네이비 배경과 자체 제작 SVG 라인 그래픽을 적용한다. 참고 사이트의 로고·영상·이미지·문구를 복제하지 않는다.
- 공통 메뉴는 어두운 배경, 본문은 밝은 표·입력 카드로 구성한다. 기존 업무 경로·권한·검토 상태를 유지한다.
- 기본 동작 버튼과 활성 탭은 파란색이다. 성공·주의·오류 상태의 의미 색과 텍스트는 별도로 유지한다.
- 외부 글꼴·이미지·스크립트를 새로 요청하지 않는다. 추가 패키지 없이 Vue 컴포넌트와 CSS로 구현한다.
- 모바일에서는 메뉴가 줄바꿈되고, 표만 내부 가로 스크롤한다. 장식은 접근성 트리에서 제외하고 키보드 포커스 표시와 모션 감소 설정을 지원한다.

검증: 프론트 타입 검사·프로덕션 빌드, 기존 테스트 28개(계산 2개·브라우저 26개) 통과. 로그인 390px 가로 넘침 없음, 사건 목록 모바일 및 판정 상세 데스크톱을 시각 확인했다.
