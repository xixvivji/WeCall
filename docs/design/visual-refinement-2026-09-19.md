# 공개 체험 화면 디자인 보완

SK AX 공식 홈페이지(https://www.skax.co.kr/, 2026-09-19 확인)의 전체 폭 히어로, 어두운 배경과 푸른 곡선, 큰 제목, 상단 메뉴, 넓은 흰색 여백을 참고했다. 회사 로고·문구·영상·이미지를 복사하지 않고 WeCall 문구와 직접 작성한 SVG를 사용했다. 외부 폰트·영상·추적 스크립트를 추가하지 않았다.

- 샘플 첫 화면을 전체 폭 배너와 상단 메뉴로 구성하고 6단계 체험 안내를 아래에 배치했다.
- 체험 시작 버튼은 현재 단계로 스크롤하고 제목에 키보드 초점을 이동한다. URL과 진행 상태를 바꾸지 않는다.
- 원문·판단·대응의 세 흐름은 설명용 표기이며 슬라이드 조작 버튼이 아니다.
- 공통 SVG는 로그인과 사건 목록에도 적용한다. 업무 폼·표·권한과 판정 로직은 기존 동작을 유지한다.
- 모바일에서 메뉴를 간소화하고 제목과 흐름 안내를 재배치한다. 자동 재생이나 움직임은 추가하지 않았다.

검증: 프론트 프로덕션 빌드, 샘플 체험 4개를 포함한 전체 프론트 테스트 35개 통과. 데스크톱과 390px 모바일 화면 확인, 모바일 가로 넘침 및 시작 버튼의 초점 이동 검증 완료.

추가 기능은 이 변경에 포함하지 않는다. 제출 준비에서는 실제 AI 실행을 제공할 접근 정책·자원 제한·독립 체험 데이터 구성이 우선이다. 이후 운영 기능 후보는 작업 기한·기한 초과 알림이며 별도로 범위와 전달 방식을 정한다.
