# AI 입력 검사와 실패 안내

2026-09-18 구현. FastAPI와 로컬 Ollama를 유지하며 외부 API나 새 AI 프레임워크를 추가하지 않는다.

## 입력

등록·원문 수정·AI 탭에서 UTF-8 바이트와 줄 수를 표시한다. 6,000바이트·80줄 이하는 크기 기준으로 허용하며 추출 가능성이나 정확성을 보장하지 않는다. Python `splitlines()`와 같은 줄 경계를 사용한다(CRLF 한 번, 마지막 줄바꿈 뒤 빈 줄 제외). 한글·이모지를 글자 수로 환산하지 않는다.

사건 원문은 기존 보관 한도까지 저장할 수 있다. AI 한도 초과 시 분석 버튼을 막고 서버도 큐 생성 전에 422로 거부한다. 원문을 자르거나 덮어쓰지 않는다. 긴 문서는 전체를 읽고 수동으로 조건을 작성한다. 예외·정정 문구를 제거해 한도에 맞추도록 유도하지 않는다.

## 오류 계약

| 원인 | 백엔드 코드 | 다음 행동 |
| --- | --- | --- |
| 입력 초과 | LOCAL_SOURCE_TOO_LONG | 전체 원문 보관, 수동 조건 작성 |
| 빈 입력 | EMPTY_SOURCE | 원문 확인 |
| 범위 밖·명확하지 않은 조건 | MANUAL_REVIEW_REQUIRED | 예외·상품별 조건 검토 후 수동 작성 |
| 모델 사용 중 | LOCAL_MODEL_BUSY | 잠시 기다린 뒤 재요청 |
| 모델 연결 실패 | LOCAL_MODEL_UNAVAILABLE | 담당자에게 실행·설치 확인 요청 |
| 서비스 연결·일반 장애 | AI_UNAVAILABLE | 담당자에게 서비스 확인 요청 |
| 모델·서버 시간 초과 | AI_TIMEOUT | 재요청 또는 수동 작성 |
| 모델 형식·근거·완료 검증 실패 | INVALID_AI_RESPONSE | 미적용, 재시도 반복 시 수동 작성 |
| 응답 크기 초과 | AI_RESPONSE_TOO_LARGE | 미적용, 담당자 확인 |
| 로컬 모델 확인 실패 | NON_LOCAL_MODEL_BLOCKED | 차단, 로컬 설정 확인 |
| 모델·연결 설정 누락 | MODEL_NOT_CONFIGURED / SERVICE_NOT_CONFIGURED | 담당자 설정 |
| 서비스 인증 거부 | AI_SERVICE_AUTH_FAILED | 담당자 인증 설정 확인 |
| 처리 중단 | WORKER_INTERRUPTED | 기록 보존, 재요청 |
| 모의 연동 제한 | MOCK_RESPONSE_DISABLED / UNSUPPORTED_FIXTURE | 로컬 모델 연결 확인 또는 수동 작성 |

FastAPI의 상태와 허용한 오류 코드만 해석한다. 알려지지 않은 응답은 일반 오류로 표시하고 임의의 upstream 메시지·본문은 전달하지 않는다. 401/403은 본문을 읽지 않고 인증 실패로 분류한다. 기존 AI_REJECTED_INPUT 기록도 안내한다. UI에는 내부 오류 코드를 그대로 노출하지 않는다.

분석 요청과 검토 권한, 같은 사건의 진행 중 중복 요청 차단, 실패 기록의 기각, 사람의 별도 승인 규칙은 유지한다. 재시도는 현재 저장된 원문 버전으로 새 작업을 생성하며 과거 실패를 덮어쓰지 않는다. 실패한 요청·저장은 입력을 지우지 않는다.
